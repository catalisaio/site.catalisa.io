## Registro por material

| Campo | Conteúdo |
|---|---|
| Nome e arquivo | Link relativo para o original |
| Origem | Autor, URL ou contexto de fornecimento, quando conhecido |
| Recebido em | Data |
| Estado | Referência, hipótese, proposta ou decisão confirmada |
| Contribuição | Qual problema de conteúdo, visual ou interação ajuda a resolver |
| Relações | IDs do catálogo, páginas do relatório e documentos de `site-v2` relacionados |
| Conflitos | Quais escolhas anteriores precisam ser reconciliadas |
| Decisão de uso | O que adotar, adaptar ou deixar de fora e por quê |
| Aplicação | Página, seção, componente ou token em que foi usado |

O [catálogo completo](../catalogo-inspiracoes.md) mantém os IDs 01 a 72. Novos materiais podem receber um prefixo próprio, como `N01`, para preservar os vínculos existentes.
